# Source index

`source_index.csv` provides one record for each of the 260 source groups represented in the final analysis union. It includes source type, cohort-specific row counts, bibliographic information, DOI verification status, redistribution-review status, and the access route.

This is a provenance index, not a republication of composition, processing, or mechanical-property values. A blank `DOI_for_access` means the inherited DOI was not sufficiently supported by the human-readable reference and the citation must be located manually.

Three inherited DOI mismatches were corrected against their reference strings:

- `ACTASRC_151`: `10.1023/A:1018676501368`
- `ACTASRC_161`: `10.1007/BF02817276`
- `ACTASRC_173`: `10.1007/s11661-002-0214-2`

See `reconstruction_instructions.md` for the controlled reconstruction procedure.
